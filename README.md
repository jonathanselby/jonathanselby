# Jonno's Garage

I'm Jonathan Selby.

I build small, opinionated tools and methods for messy enterprise problems.

My background is in enterprise technology, architecture and commercial delivery. These days I spend a lot of time using AI to make systems easier to understand, decisions easier to defend, and useful software faster to build.

The garage opened in October 2026, but on day 1 had a lot of historic thinking uploaded.

Current interests: AI-native engineering, Go, system design, data, code understanding, constrained engineering and practical operating tools.

## Built Micro Components

- **[Three-Lane Model Harness](https://github.com/jonathanselby/three-lane-model-harness)** — a deliberately small Go harness for routing explicitly classified AI work across simple, standard and complex model lanes.
- **[Enterprise AI Workbench](https://github.com/jonathanselby/enterprise-ai-workbench)** — small, reusable AI workflows for research, decisions, risks, policies and technical analysis.
- **[Data Dictionary First](https://github.com/jonathanselby/data-dictionary-first)** — a practical case for governed data dictionaries and runtime semantics before committing to an enterprise ontology.

## Methods

- **[Codebase to EDD](https://github.com/jonathanselby/codebase-to-edd)** — turn an unfamiliar codebase into an engineering design document, system map and set of architecture diagrams.
- **[Cross-Cloud Architecture](https://github.com/jonathanselby/cross-cloud-architecture)** — Translate the architecture, not the product catalogue. AWS, Azure and Google Cloud.
- **[Technology Sourcing Toolkit](https://github.com/jonathanselby/technology-sourcing-toolkit)** — Technology buying decisions are architecture decisions with a contract attached.
- **[Capability Modelling](https://github.com/jonathanselby/capability-modelling)** — Model what the organisation must be able to do, not its org chart.
