# Jonno's Garage

I'm Jonathan Selby.

I build enterprise applications in go. I build small nimble games and opinionated mini monoliths, tools and methods for messy enterprise problems.

My background is in enterprise technology, architecture and commercial delivery. These days I spend a lot of time using AI to make systems easier to understand, decisions easier to defend, and useful software faster to build.

The garage opened in October 2026, but on day 1 had a lot of historic thinking uploaded.

Current interests: AI-native engineering, Go, system design, data, code understanding, constrained engineering and practical operating tools.

## Built Micro Components

- **[Three-Lane Model Harness](https://github.com/jonathanselby/three-lane-model-harness)** — a deliberately small Go harness for routing explicitly classified AI work across simple, standard and complex model lanes.
- **[Enterprise AI Workbench](https://github.com/jonathanselby/enterprise-ai-workbench)** — small, reusable AI workflows for research, decisions, risks, policies and technical analysis.
- **[Data Dictionary First](https://github.com/jonathanselby/data-dictionary-first)** — a practical case for governed data dictionaries and runtime semantics before committing to an enterprise ontology.
- **[Governed Retrieval](https://github.com/jonathanselby/governed-retrieval)** — retrieval that filters access before ranking, cites supporting material and refuses unsupported queries.
- **[Evaluation Service](https://github.com/jonathanselby/evaluation-service)** — deterministic evaluation and regression gates for recorded system outputs.
- **[Governed MCP](https://github.com/jonathanselby/governed-mcp)** — a thin MCP adapter that exposes application commands without becoming a second approval system.
- **[Decision Ledger](https://github.com/jonathanselby/decision-ledger)** — an append-only, independently verifiable ledger for human decisions.
- **[Authentication](https://github.com/jonathanselby/authentication)** — verification for several authentication paths without becoming an identity platform.
- **[Authorisation and Dual Control](https://github.com/jonathanselby/authorisation-dual-control)** — deterministic role, need-to-know, delegation and maker-checker decisions.
- **[Out-of-Band Verification](https://github.com/jonathanselby/out-of-band-verification)** — verification using pre-registered challenge and callback material rather than inbound contact details.
- **[Obligation Clock](https://github.com/jonathanselby/obligation-clock)** — deterministic deadline calculation from explicit triggers, timezones and calendars.
- **[Notifier](https://github.com/jonathanselby/notifier)** — explicit notification delivery attempts with visible delivered, failed or suppressed outcomes.
- **[Go App Shell](https://github.com/jonathanselby/go-app-shell)** — a small, framework-free presentation shell for server-rendered Go web applications.
