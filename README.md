# Jonno's Garage

I'm Jonathan Selby.

I build small, opinionated tools and methods for messy enterprise problems.

My background is in enterprise technology, architecture and commercial delivery. These days I spend a lot of time using AI to make systems easier to understand, decisions easier to defend, and useful software faster to build.

Current interests: AI-native engineering, Go, system design, data, code understanding, constrained engineering and practical operating tools.

## Featured work

- **Codebase to EDD** — turn an unfamiliar codebase into an engineering design document, system map and set of architecture diagrams.
- **Three-Lane Model Harness** — a deliberately small Go harness for routing explicitly classified AI work across simple, standard and complex model lanes.
- **Enterprise AI Workbench** — small, reusable AI workflows for research, decisions, risks, policies and technical analysis.
- **Data Dictionary First** — a practical case for governed data dictionaries and runtime semantics before committing to an enterprise ontology.
- **Small Organisation Ops** — deliberately lightweight project, risk, policy and decision tools.
- **Engineering Under Constraints** — lessons from early computing and mission systems that remain useful in modern software.
